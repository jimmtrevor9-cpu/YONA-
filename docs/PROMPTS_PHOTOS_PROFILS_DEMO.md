# Descriptions pour créer les photos des 40 profils de démonstration

Une description par profil, à coller dans un outil d'images (Midjourney, DALL·E, Adobe Firefly…).

**Règles obligatoires**

- Utilisez **uniquement le texte** : ne donnez jamais à l'outil la photo d'une personne réelle (pas d'« image de référence », pas de « remplacement de visage », pas de retouche d'une photo existante). Sinon l'image reste celle de cette personne.
- Une image = un profil. Vérifiez que le visage obtenu ne ressemble pas à quelqu'un que vous connaissez.
- Déposez ensuite l'image dans `/admin` → **Profils de démo** → choisissez « Image générée : personne qui n'existe pas ».
- Les profils restent signalés aux membres par l'étiquette « Profil de démonstration ».

Les descriptions sont en anglais, langue que ces outils comprennent le mieux. Format conseillé : portrait vertical (3:4).
